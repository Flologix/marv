The `report` command needs some work before the next release. Scripts that call it want machine-readable output, so it should take a `--json` flag that prints the report as JSON instead of the text table: an object with `rows` (each `{ "name", "amount" }`, in the order the table shows them) and `total`. While you're in there, `--limit` is a confusing name for how many rows to show, so rename it to `--top`; plenty of existing scripts still pass `--limit`, though, so keep accepting it for now, but print a warning to stderr saying it's deprecated and to use `--top` instead. Someone also noticed that the total at the bottom never matches the amounts in the file: it looks like the first row is always left out of it. And since people mostly learn the flags from the README, its usage section should document the new options, with `--top` rather than `--limit`; please also add an entry under Unreleased in CHANGELOG.md describing what changed.
