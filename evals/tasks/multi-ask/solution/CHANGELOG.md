# Changelog

## [Unreleased]

- `--json` prints the report as JSON (`rows` and `total`).
- `--limit` is now `--top`; `--limit` still works but warns that it's deprecated.
- The total no longer leaves out the first row.

## [1.3.0] - 2026-09-01

- Rows are sorted by amount, largest first.

## [1.2.0] - 2026-07-14

- `--limit N` shows only the N largest rows.
