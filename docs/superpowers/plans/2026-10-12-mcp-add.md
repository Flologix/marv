# /mcp add Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Issue #6. `/mcp add <npm | pypi: | https URL | GitHub repo | registry name>` works out a pinned `~/.marv/mcp.json` entry, shows it in one approval, writes exactly that entry and starts the server in the running session. `/mcp search` lists the official MCP Registry; `/mcp remove` takes a personal server out.

**Architecture:** A new folder `src/mcp/install/` holds the pure source parser and one resolver per source, each returning a `Proposal` (`name`, the raw `entry` to write, `facts` to show). Resolvers fetch through an injected `get` (Marv's own `src/tools/web/fetch.ts`), so tests use `Bun.serve`. `src/mcp/personal-file.ts` adds and removes entries in `~/.marv/mcp.json`. `McpManager` gains `add`/`remove`. The App wires it: resolve → its own `ApprovalRequest` (`once: true`) → write → `mcp.add`. The session needs no new logic: #14's `announce()` already lists tools not yet announced.

**Tech Stack:** Bun, TypeScript, zod, `@modelcontextprotocol/sdk` (fixture server), `bun:test`, `ink-testing-library`.

Spec: `docs/superpowers/specs/2026-10-12-mcp-add.md` (to be approved; settle its open questions first: they don't change Tasks 1–9).

**Background for the engineer:**
- Read `CLAUDE.md`: **MCP servers** (incl. deferred tools), **Tools** (approval), **Sandbox**, **Private files**, **Prompt cache**.
- **The rule:** what the approval shows is built from the `entry` that gets written (`displayOf` from `src/mcp/config.ts`, export it), and nothing is fetched after the yes.
- **No network in tests:** resolvers take `get: typeof get` and an options object; tests pass `(url, o) => get(url, { ...o, allowPrivate: true })` against a local `Bun.serve`. Fixtures in `tests/fixtures/mcp-install/` are captured once from the real APIs (`curl -s https://registry.npmjs.org/@modelcontextprotocol/server-filesystem > …`, the registry's `/v0/servers?search=filesystem&version=latest`, a PyPI JSON) and trimmed by hand.
- **Conventions:** `.ts` extensions in imports, `import type`, comments say *why*. Commands: `bun test <substring>`, `bun run typecheck`, `bun test`.
